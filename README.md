# AI Workplace Productivity Assistant 💗

## 1. Project Overview

The **AI Workplace Productivity Assistant** is a modern, responsive web application designed to help professionals improve workplace productivity by using Artificial Intelligence (AI).

The application provides intelligent tools that simplify everyday workplace tasks, including generating professional emails, researching information, summarising content and answering workplace-related questions.

The system features a clean, modern SaaS dashboard with a pink and light-grey colour scheme, making it user-friendly, accessible and visually appealing.

The application is designed as a frontend-only project without a backend or database.

## 2. Features Implemented

### 📧 Smart Email Generator
- Generate professional emails using AI.
- Supports three communication tones:
  - Formal
  - Friendly
  - Persuasive
- Editable generated email content.
- Copy generated emails.
- Regenerate email responses.

### 🔍 AI Research Assistant
- Enter research topics or questions.
- Summarise pasted articles and information.
- Accept website URLs for research.
- Generate key findings and insights.
- Provide recommendations based on research.

### 💬 AI Workplace Chatbot
- Interactive AI chatbot interface.
- Answer workplace-related questions.
- Assist with business and productivity tasks.
- Provide context-aware responses.
- Support ongoing conversations.

### 🎨 User Interface
- Modern SaaS dashboard design.
- Pink, white and light-grey colour scheme.
- Sidebar navigation.
- Responsive desktop and mobile layouts.
- User-friendly input forms.
- Editable AI-generated outputs.
- Responsible AI disclaimer.

## 4. Setup Instructions

Follow these steps to run the application locally.

### Step 1: Clone the Repository

Open your terminal and run:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Navigate to the Project Folder

```bash
cd ai-workplace-productivity-assistant
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Start the Development Server

```bash
npm run dev
```

### Step 5: Open the Application

Open your browser and navigate to the local development URL displayed in your terminal, usually:

```text
http://localhost:5173
```

## 6. Responsible AI Disclaimer

This application uses AI technology to assist with workplace productivity.

AI-generated information may occasionally contain errors or inaccuracies. Users should review, verify and edit generated content before using it for professional purposes.

Users should avoid entering confidential business information, personal information or sensitive company data.

AI-generated responses should be treated as assistance rather than a replacement for professional judgement.

## 7. Backend and Database

This project is designed as a frontend-only application.

- No backend server required.
- No database required.
- No authentication system.
- Browser localStorage can be used for temporary data storage.
- Real AI-generated responses require an external AI service and appropriate API integration.
