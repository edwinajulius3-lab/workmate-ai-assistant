# Workmate AI Assistant

Build a modern, responsive SaaS web application called AI Workplace Productivity Assistant.

Create a professional dashboard using a soft pink (#E879A8), white and light grey (#F5F5F7) colour scheme. Include a modern sidebar, navigation icons, clean cards and responsive layouts.

Main Features:

Smart Email Generator: Generate personalised, professional emails from user instructions. Include Formal, Friendly and Persuasive tones, with editable outputs, copy and regenerate buttons.

AI Research Assistant: Allow users to enter topics, paste articles or provide website URLs. Generate meaningful summaries, key findings, insights and actionable recommendations.

AI Workplace Chatbot: Create an interactive chatbot that answers workplace, business and productivity questions with relevant, context-aware AI responses.

Requirements:

Fully functional frontend.

Structured AI prompts for accurate responses.

Editable AI-generated content.

Loading animations and error handling.

Copy-to-clipboard functionality.

Chat history and temporary localStorage.

Responsible AI disclaimer.

IMPORTANT TECHNICAL INSTRUCTIONS:

Frontend only. No backend, database, authentication or Supabase.

Do not use generic hardcoded responses or pretend simulated responses are AI-generated.

Use a browser-compatible AI integration where possible, with an API key entered securely by the user.

If no AI API is configured, clearly explain that AI functionality requires an API connection.

Keep the application lightweight, attractive and easy to use.
